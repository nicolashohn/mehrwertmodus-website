Bereitstellung der Website

Die Website wird über GitHub Pages bereitgestellt. Beim Aufruf können technisch erforderliche Verbindungsdaten, beispielsweise IP-Adresse, Zeitpunkt des Zugriffs und Browserinformationen, verarbeitet werden. Welche Daten GitHub im Einzelnen speichert, wie lange diese gespeichert werden und ob Übermittlungen in Drittländer erfolgen, muss anhand der aktuellen Anbieterinformationen überprüft und hier ergänzt werden.
